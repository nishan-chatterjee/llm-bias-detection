# Historical hate/offensive-speech material

`visuals_offensive_speech.ipynb` is preserved with its original rendered
outputs. It combines the released hate-speech experiment with a distinct
offensive-speech dataset that is not part of this paper release. It also
contains raw-logit temperature transforms even though the hate-speech handoff
does not contain raw vocabulary logits, and its final stored cell ends with a
historical `KeyError`.

Use `tasks/hate-speech/analysis/notebooks/01_hate_speech_analysis_primary_models.ipynb`
for the complete runnable release analysis.
