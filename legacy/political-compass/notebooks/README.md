# Historical Political Compass notebooks

These are the original output-rich research notebooks with their rendered
figures preserved. They are not the canonical release notebooks.

- `mcq-analysis-v1-300.ipynb` expects raw wide CSVs and a locally generated
  scorer `.npz` that is not redistributed.
- `chat-analysis-v2-300.ipynb` includes GaMS and Qwen 0.6B/1.7B experiments
  outside the paper's primary model set.
- `mcq-chat-analysis-v2-300.ipynb` includes exploratory RQs and dependencies
  not used as release evidence.

Use `tasks/political-compass/analysis/notebooks/` for the complete runnable
primary-model analysis.
